# Flash · Edge 视频倍速扩展

原生 JavaScript / HTML / CSS，Manifest V3，无依赖、无后端、无外部请求。直接加载本文件夹即可使用，无需构建。

## 项目结构

```text
Flash/
  manifest.json
  background.js          设置、存储、快捷键、iframe 报告转发
  content.js             视频发现、倍率维护、Shadow DOM 悬浮面板
  popup/                 popup.html / popup.css / popup.js
  styles/content.css     Shadow DOM 内加载的样式
  icons/                 icon16.png / icon48.png / icon128.png
  tests/                 unit.cjs / content.cjs / manual.html / manual.js / frame.html
  README.md
```

## 安装

1. 打开 `edge://extensions/`，启用“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择 **Flash 文件夹**（包含 manifest.json 的这一层）。
3. 安装后刷新已打开的普通网页。可在 Edge 扩展菜单将 Flash 固定到工具栏。
4. 如要测试本地 HTML，打开扩展详情，启用“允许访问文件 URL”。隐私窗口需要另行授权。

## 使用

点击工具栏 Flash 图标，自定义输入正数，回车或离开输入框应用。常用预设、±0.1 按钮也可使用。推荐 0.1–16×；接受任意有限正数（包括 3.7、6.25、12），最终由媒体引擎决定是否支持。

点击“显示 / 隐藏网页面板”打开悬浮面板。拖动标题栏移动，× 隐藏，同一按钮可再次打开。位置持久保存，面板默认隐藏。表单控件使用闭合 Shadow DOM 隔离页面样式。

启用状态、倍率、记忆选项、自动应用选项、面板位置在所有受支持页面同步。**倍率是全局设置**，修改后会作用于所有已打开且注入扩展的网页。关闭“记住当前速度”后，本次浏览器会话仍保留倍率，浏览器会话结束后恢复 1×。Edge 后台运行可能延长会话。

关闭“自动应用新视频”后，新发现视频只登记、不修改；已有受管理视频继续保持倍率。手动更改倍率或重新启用时，对当前全部视频应用。禁用后停止修改，不强行恢复 1×，避免影响网页已有状态。禁用期间调节倍率仅更新目标，重新启用才应用。

快捷键：Alt+Shift+逗号（<）降低一档，Alt+Shift+句号（>）提高一档，Alt+Shift+0 恢复 1×。档位为 0.1、0.25、0.5、0.75、1、1.25、1.5、2、2.5、3、4、5、8、10、16。自定义值向相邻档位移动。若系统或其他扩展占用，在 `edge://extensions/shortcuts` 设置。

## 实现与资源控制

- 所有 `<video>` 默认一起控制；监听 `ratechange` 和 `loadedmetadata`。
- MutationObserver 合并为每 100ms 最多一次发现扫描；每 5 秒发现开放 Shadow Root、清理离开 DOM 的节点并汇报 iframe，无高频倍率轮询。
- 网站在 5 秒内触发五次纠正后停止争抢，显示不支持提示。重新更改目标倍率、重新启用或媒体元数据加载时恢复尝试。
- all_frames、match_about_blank、match_origin_as_fallback 在浏览器允许范围内覆盖框架；各框架独立操作自身 DOM，经扩展通信汇总状态，不读取跨源 DOM。
- 全屏容器内重挂面板；原生 video 全屏时隐藏面板，倍率和扩展快捷键继续有效。退出后可从弹窗重新打开。
- 仅申请 storage 及 HTTP/HTTPS/file 网页权限，无历史记录、网络拦截、脚本动态执行权限。广泛站点访问用于自动发现任意站点及跨源 iframe。可在 Edge 详情限制站点访问，但会相应影响自动应用。

## 验证与手动验收

运行 `node Flash/tests/unit.cjs` 和 `node Flash/tests/content.cjs`（在项目父目录）可检查实际后台代码和内容脚本。内容脚本测试使用 DOM 测试替身，**不等同于真实视频播放测试**。

已通过：设置持久化/会话语义、非法输入、三个命令处理、并发更新、Manifest 引用检查；内容脚本的多个视频、2×、3.7×、动态发现、重置纠正、禁用/重新启用、关闭自动应用、设置失败与恢复、移除节点清理。JavaScript 语法检查通过。

环境检测到 Edge；尝试独立配置无头启动，未获得可验证的 DOM 输出，故**未确认真实 Edge 扩展安装、媒体播放、快捷键注册、iframe 注入、全屏视觉表现**。Bilibili、YouTube、课程网站未做实站验收。请按以下步骤确认：

1. 加载扩展并允许文件 URL，打开 `tests/manual.html`，任选本地视频（文件不上传）。也可在此目录用 `python -m http.server 8765` 后打开 `http://localhost:8765/tests/manual.html`，不需文件权限。
2. 播放视频，从 1× 设置 2×，查看测试台各视频倍率及实际播放速度。
3. 输入 3.7，确认三个视频与 iframe 视频均为 3.7×。
4. “动态添加视频”，确认新增视频自动为 3.7×；测试关闭自动应用后的新视频保持 1×。
5. 启用记忆并刷新，确认恢复 3.7×；完整退出再打开浏览器再次确认。
6. 禁用扩展，在测试台点击“网站模拟：重置为 1x”，确认保持 1×。
7. 重新启用，确认所有视频恢复目标倍率。
8. 测试三个快捷键；在快捷键设置页确认无冲突。
9. 检查同源 iframe；跨源 iframe 可在其他端口部署 frame.html 嵌入，确认授权后独立注入。
10. “容器全屏”测试悬浮面板；再通过视频原生控件全屏，确认快捷键仍改变倍率。
11. 输入 0、负数、非数字，确认提示；输入浏览器不支持的极端倍率，确认显示失败信息。网页连续争抢倍率时确认扩展会停止重试。

## 已知限制及扩展方向

无法保证所有网站可用。Canvas/WebGL、非 HTML5 播放器不受支持。DRM 或特殊流媒体是否可调由播放器决定，DRM 本身并不必然禁止调速。关闭的 Shadow Root、浏览器保护页、扩展商店、受安全策略或站点授权限制的 iframe 可能不可访问。新权限或扩展更新后需刷新旧页面。无视频时明确提示，存在不支持或持续重置的视频时显示失败数量。框架报告最多延迟约 5 秒，导航或移除框架的旧统计最长约 12 秒过期。

极端倍率可能影响音频或被引擎拒绝；成功设置 playbackRate 不代表网站能流畅播放。面板无法覆盖原生视频全屏层；隐藏面板不会禁用扩展。可后续添加按域名记忆、单个视频选择、自定义快捷键档位、导入导出设置。
